## Platform
web

## Purpose
Saad Akhtar's personal portfolio at saadsalam.dev. Visitors explore work, skills, experience and contact information through a working CRT monitor, or watch a seven-chapter personal transmission.

## Constraints
The supplied SA-01 master brief is the product and visual direction. Vite, React 18, strict TypeScript, Framer Motion, ordinary React screen content, hash navigation and synthesized opt-in audio. No iframe. All controls work. Reduced motion, plain mode and keyboard access are required. Existing admin and project routes remain available. The original portfolio content, layout, animations and admin-backed data remain inside the CRT. Monitor interface copy and optional terminal data live in src/data/content.ts; Story Mode lives in src/data/story.ts.

## Evidence
Existing portfolio source supplies Lahore, AI studies at UMT, and project subjects. Biography details in brackets require personalization. No invented clients or testimonials. The original portfolio retains its existing contact links. The optional terminal contact component supports VITE_CONTACT_ENDPOINT and a mail-application fallback.

## Next-version direction
The user requested two complete browser desktop experiences: a Windows 98-inspired OS on the current charcoal CRT and an original minimalist 2026 OS on a soft-edged thin-bezel monitor, with mixed Apple-style sans/Claude-style italic typography. Normal website arrival shows both complete computer setups, vintage left and modern right, as in the supplied sketch. An OS-choice popup triggers a smooth cinematic camera approach and blend into the selected live desktop, targeting 60fps; one monitor fills the viewport after entry. Both require working applications and realistic CGI screen-driven bezel lighting, with production completeness. The later direction removes tables and stands, adds a highly animated greeting/chooser, and requires six distinct games in each OS. The original portfolio remains an application in both editions. [OS_DESIGN.md](OS_DESIGN.md) and [docs/OS_ENGINEERING.md](docs/OS_ENGINEERING.md) specify this planned build; the OS shells, animated arrival/camera sequence, utility apps and distinct game collections are implemented locally. Full CGI reflection calibration and the complete release matrix remain outstanding.
