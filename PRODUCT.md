# SA-01 Personal Monitor

<!-- impeccable:product-schema 1 -->

## Platform
web

## Purpose
Saad Akhtar's personal portfolio at saadsalam.dev. Visitors explore work, skills, experience and contact information through a working CRT monitor, or watch a seven-chapter personal transmission.

## Constraints
The supplied SA-01 master brief is the product and visual direction. Vite, React 18, strict TypeScript, Framer Motion, ordinary React screen content, hash navigation and synthesized opt-in audio. No iframe. All controls work. Reduced motion, plain mode and keyboard access are required. Existing admin and project routes remain available. The original portfolio content, layout, animations and admin-backed data remain inside the CRT. Monitor interface copy and optional terminal data live in src/data/content.ts; Story Mode lives in src/data/story.ts.

## Evidence
Existing portfolio source supplies Lahore, AI studies at UMT, and project subjects. Biography details in brackets require personalization. No invented clients or testimonials. The original portfolio retains its existing contact links. The optional terminal contact component supports VITE_CONTACT_ENDPOINT and a mail-application fallback.
